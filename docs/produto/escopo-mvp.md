# Escopo do MVP

> **Assunto:** o que é o MVP, o ambiente e os 13 critérios globais de aceite · **Componente:** Projeto · **Atualizado:** 2026-10-12

## O que é o MVP

Tudo o que a especificação original descreve é o MVP, e só isso. Nenhum documento acrescenta funcionalidade além dela; escolhas de detalhe necessárias para implementar (valores padrão, nomes, formatos) são propostas nos documentos e marcadas como "padrão" quando configuráveis.

**Ambiente:**
- Quatro usos: só Linux, Linux + Windows, Windows + Linux e só Windows; em todos, o Core aceita N nós ([ADR 0020](../decisoes/0020-quatro-usos-core-em-linux-ou-windows.md)).
- Linux: Ubuntu na versão LTS atual, registrada na instalação. Windows: 11 ou superior. Os dois conferidos pelo [checklist](../plataforma/checklist.md).
- Rede local. Um nó de outra rede usa o endereço do Core configurado à mão ([descoberta](../conectividade/descoberta.md)).
- Repositórios na conta pessoal do GitHub do Dono ([ADR 0015](../decisoes/0015-epico-como-rotulo.md)).
- Sem interface gráfica além do painel no navegador; os agentes são de terminal.
