# Escopo do MVP

> **Assunto:** o que é o MVP, o ambiente e os 15 critérios globais de aceite · **Componente:** Projeto · **Atualizado:** 2026-10-13

## O que é o MVP

O MVP é a especificação original mais as decisões do usuário registradas depois dela (nos ADRs, como a autoatualização do Mestre, [0019](../decisoes/0019-autoatualizacao-por-releases.md), os dois sistemas sem interface gráfica, [0020](../decisoes/0020-quatro-usos-core-em-linux-ou-windows.md), o Operador do PC, [0021](../decisoes/0021-operador-do-pc.md), e a Guilda com Cidadela e Torres, [0022](../decisoes/0022-guilda-cidadela-e-torres.md)), e só isso. Os CLIs dos provedores se atualizam sozinhos; o Mestre não os atualiza nem desliga a autoatualização deles, só detecta a versão nova e roda a conformidade ([atualização dos CLIs](../provedores/atualizacao-dos-clis.md)). Nenhum documento acrescenta funcionalidade além da spec e das decisões registradas; escolhas de detalhe necessárias para implementar (valores padrão, nomes, formatos) são propostas nos documentos e marcadas como "padrão" quando configuráveis.

**Ambiente:**
- Quatro composições da Guilda: só Linux (Guilda de uma máquina Linux), Cidadela Linux + Torre Windows, Cidadela Windows + Torre Linux e só Windows; em todas, a Guilda aceita N máquinas, e qualquer uma pode virar Cidadela ([ADR 0022](../decisoes/0022-guilda-cidadela-e-torres.md)).
- Linux: Ubuntu na versão LTS atual, registrada na instalação. Windows: 11 ou superior. Os dois conferidos pelo [checklist](../plataforma/checklist.md).
- Rede local. Uma máquina de outra rede usa o endereço da Guilda configurado à mão ([descoberta](../conectividade/descoberta.md)).
- Repositórios na conta pessoal do GitHub do Dono ([ADR 0015](../decisoes/0015-epico-como-rotulo.md)).
- Sem interface gráfica além do painel no navegador; os agentes são de terminal.
